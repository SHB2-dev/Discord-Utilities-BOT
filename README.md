# SHB2 Discord Utilities BOT

## 主な機能

1. BUMP通知
- DISBOARDの二時間ごとにBUMP出来る機能用にタイマーを追加します
- どこのチャンネルでも、検知してくれるはず(メッセージを送信できるかは権限によりけり)
2. ルールの同意チェック
- ルールに同意したかどうかがチェックできます
- また、同意したかそうでないかにかかわらず、管理用チャンネルにその旨が送信されます

## 現状の問題点

幾つかの部分はハードコードされているので変更できません

1. ルールに同意した/同意していないロール <- ロールが変更される可能性は低いため、優先度も低い
2. 管理用チャンネルのID <- これも変わる可能性が低い

これから先、これらが変更される際にconfigに追加、って形になるかも
